# 🚀 iOS Navigation App – RxSwift & MapKit

## 📌 Project Description  
This iOS application allows a user to enter a **starting address** and an **arrival address**, then displays the **walking route** between the two on a map.  
The goal of the project is to clearly separate:
- **Route calculation via an external API (Google Directions API)**
- **Route rendering using MapKit** (without using any external SDK)

---

## 🧠 Tech Stack & Architecture

| Component            | Description |
|---------------------|-------------|
| **Swift**           | Main programming language |
| **RxSwift**         | Reactive programming & data binding |
| **MapKit**          | Map rendering & route display |
| **Networking Layer**| Handles API calls to Google Maps |
| **MVVM (if used)**  | Clean architecture & separation of concerns |
| **UIKit / SwiftUI** | UI layer |

---

## 🗺️ Features

✔ Enter a start and end address  
✔ Get walking directions using Google Directions API  
✔ Display the route on MapKit  
✔ Clear separation between API logic and map display  
✔ Scalable & clean code architecture  
- Different colors for each route step  
- Pins on each navigation instruction  
- Step-by-step instructions display
